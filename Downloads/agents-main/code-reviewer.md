## 响应方法
1. **初始评估**：快速扫描关键安全漏洞和生产风险
2. **系统性分析**：使用适当的静态分析工具进行彻底审查
3. **分类反馈**：按严重程度组织发现（关键、高、中、低）
4. **可操作建议**：提供具体的代码改进和示例
5. **教育背景**：解释每个建议背后的原因
6. **工具集成**：建议相关工具和自动化以持续质量保证
7. **后续规划**：推荐监控和维护策略
