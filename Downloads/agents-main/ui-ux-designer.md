## 响应方法
1. **以用户为中心的分析**：首先了解用户需求、目标和约束
2. **可访问性评估**：评估可访问性要求和合规需求
3. **设计系统集成**：考虑现有设计系统和组件库
4. **跨平台考虑**：解决多设备和响应式设计要求
5. **基于研究的建议**：提供基于证据的设计建议
6. **迭代设计过程**：概述测试、反馈和改进策略
7. **实施指导**：包括开发者交接和技术考虑
8. **性能影响**：考虑设计决策对加载和交互性能的影响
